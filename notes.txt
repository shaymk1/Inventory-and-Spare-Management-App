text
FUNCTION: borrow_spare

USER GOAL: Quickly get parts for repair while maintaining accurate inventory

INPUTS:
  - technician_id (who is borrowing)
  - spare_id (which part)
  - quantity (how many)

BUSINESS RULES:
  - Quantity must be positive integer
  - Cannot exceed available stock
  - Stock cannot go negative
  - Must log transaction for audit trail
  - Must check for low stock after update

STEPS:

1. VALIDATE USER PERMISSIONS
   - Check user role allows borrowing
   - Check user is active/not blocked

2. VALIDATE SPARE
   - Ensure spare exists and is active
   - Check spare is not marked "do not borrow"

3. VALIDATE QUANTITY
   - quantity > 0
   - quantity <= available_stock

4. CALCULATE NEW STOCK
   - new_quantity = current_quantity - quantity

5. BEGIN TRANSACTION (Atomic operation)

6. UPDATE STOCK
   - SET quantity = new_quantity WHERE id = spare_id

7. RECORD TRANSACTION
   - INSERT into movements table with all details

8. CHECK LOW STOCK
   - IF new_quantity < low_threshold:
        CREATE alert record
        SHOW warning to user
        (Email alert scheduled separately)

9. COMMIT TRANSACTION

10. PROVIDE FEEDBACK
    - Show success message with details
    - Show new stock level
    - Show warning if low stock

ERROR HANDLING:
- Insufficient stock: Suggest partial borrow
- Database error: Rollback, retry once, then friendly error
- Network/offline: Queue transaction for later sync

Example: Why on_delete=models.CASCADE
text
PROBLEM: If user deleted, what happens to their orders?

THINKING:
1. User has orders → foreign key
2. If delete user → orders orphaned
3. Options: delete orders too? keep? set null?
4. `CASCADE` = "delete orders too"
5. `PROTECT` = "prevent delete if orders exist"
6. `SET_NULL` = "set user_id to NULL"

NOT MAGIC: Just database relationships 101!

def generate_report():
    """Create a simple text report"""
    
    # Get data
    total_spares = db.execute("SELECT COUNT(*) FROM spares")[0][0]
    low_stock = db.execute("SELECT COUNT(*) FROM spares WHERE quantity < low_threshold")[0][0]
    
    # Weekly movements
    weekly_movements = db.execute("""
        SELECT COUNT(*) FROM movements 
        WHERE movement_date >= date('now', '-7 days')
    """)[0][0]
    
    # Build report
    report = f"""
    WEEKLY SPARE PARTS REPORT
    Generated: {datetime.now().strftime('%Y-%m-%d')}
    
    📦 INVENTORY SUMMARY:
    • Total Spares: {total_spares} items
    • Low Stock Items: {low_stock}
    
    📈 WEEKLY ACTIVITY:
    • Total Movements: {weekly_movements}
    
    ⚠️ LOW STOCK ITEMS:
    """
    
    # Add low stock items
    low_items = db.execute("""
        SELECT name, quantity, low_threshold 
        FROM spares 
        WHERE quantity < low_threshold
        ORDER BY quantity ASC
    """)
    
    for name, qty, threshold in low_items:
        report += f"• {name} - {qty} left (threshold: {threshold})\n"
    
    return report

"Dead Stock" Detection — The GOLD Feature!
This is what separates basic tracking from smart inventory management!

What is "Dead Stock"?
Items that:

Haven't moved in X months (sitting on shelf)

High quantity but low usage (overstocked)

Obsolete/replaced by better items

Seasonal items out of season

Simple Dead Stock Detection Algorithm:
Option 1: Time-Based (Simplest)
sql
-- Items not borrowed in last 6 months
SELECT s.* 
FROM spares s
LEFT JOIN movements m ON s.id = m.spare_id 
    AND m.movement_date >= date('now', '-6 months')
WHERE m.id IS NULL
AND s.quantity > 0;
Option 2: Usage Ratio
sql
-- (Quantity on shelf) / (Monthly usage rate)
-- High ratio = dead stock
SELECT 
    s.*,
    s.quantity as stock_on_hand,
    COALESCE(SUM(CASE WHEN m.movement_type = 'borrow' THEN m.quantity ELSE 0 END), 0) as monthly_usage,
    CASE 
        WHEN monthly_usage = 0 THEN 999  -- Never used = definitely dead
        ELSE s.quantity / monthly_usage   -- Months of supply
    END as months_of_supply
FROM spares s
LEFT JOIN movements m ON s.id = m.spare_id 
    AND m.movement_date >= date('now', '-30 days')
GROUP BY s.id
HAVING months_of_supply > 6;  -- More than 6 months supply = dead stock

def find_dead_stock(months=6):
    """Find items not used in X months"""
    query = """
        SELECT s.code, s.name, s.quantity, 
               MAX(m.movement_date) as last_used
        FROM spares s
        LEFT JOIN movements m ON s.id = m.spare_id
        GROUP BY s.id
        HAVING last_used < date('now', ?) 
           OR last_used IS NULL
        ORDER BY s.quantity DESC
    """
    
    results = db.execute(query, (f'-{months} months',))
    return results

  def _add_spare(self):

        # Get values from form

        if not name or not code:
            self._show_message("❌ Error", "Name and Code are required!", "error")
            return

        try:
            quantity = int(quantity) if quantity else 0
            threshold = int(threshold) if threshold else 5
        except ValueError:
            self._show_message(
                "❌ Error", "Quantity and Threshold must be numbers!", "error"
            )
            return

        if quantity < 0 or threshold < 0:
            self._show_message(

            return

        # Prepare image path

     def _process_borrow(self):
        """Process the borrow request"""
        # Get form values
        if not self.spare_combo:
            self._show_error("No spares available to borrow")
            return

        selected_index = self.spare_combo.current()
        if selected_index < 0:
            self._show_error("Please select a spare")
            return

        spare = self.current_spares[selected_index]
        spare_id = spare["id"]
        spare_name = spare["name"]
        available_qty = spare["quantity"]

        # Get quantity to borrow
        qty_text = self.quantity_entry.get().strip()
        if not qty_text:
            self._show_error("Please enter quantity to borrow")
            return

        try:
            borrow_qty = int(qty_text)
            if borrow_qty <= 0:
                self._show_error("Quantity must be greater than 0")
                return
            if borrow_qty > available_qty:
                self._show_error(f"Cannot borrow more than available ({available_qty})")
                return
        except ValueError:
            self._show_error("Quantity must be a number")
            return

        # Get borrower name
        borrower = self.borrower_entry.get().strip()
        if not borrower:
            self._show_error("Please enter borrower name")
            return

        # Get notes
        notes = self.notes_text.get("1.0", "end-1c").strip()

        try:
            # Start transaction
            # 1. Update spare quantity
            db.execute(
                "UPDATE spares SET quantity = quantity - ? WHERE id = ?",
                (borrow_qty, spare_id),
            )

            # 2. Log movement
            db.execute(
                """
                INSERT INTO movements (spare_id, user_id, quantity, movement_type, notes)
                VALUES (?, ?, ?, 'borrow', ?)
                """,
                (
                    spare_id,
                    self.user_info.get("id", 1),
                    borrow_qty,
                    notes or f"Borrowed by {borrower}",
                ),
            )

            # Show success message
            self._show_success(f"Successfully borrowed {borrow_qty} of {spare_name}")

            # Reset form and reload spares
            self._reset_form()
            self._load_spares()

            # Update dropdown if needed
            if self.spare_combo:
                spare_options = [
                    f"{s['name']} ({s['code']}) - Qty: {s['quantity']}"
                    for s in self.current_spares
                ]
                self.spare_combo.configure(values=spare_options)

        except Exception as e:
            self._show_error(f"Database error: {str(e)}")
